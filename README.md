# Taskloom

Build automations by dragging blocks onto a canvas and connecting them, instead of
writing a script each time: run and save queries, schedule them, retry with backoff,
move files to servers, watch and restart remote apps, build reports and email them.

Runs on Windows and Linux without admin/root rights.

**Status:** design phase. See [docs/DESIGN.md](docs/DESIGN.md).
